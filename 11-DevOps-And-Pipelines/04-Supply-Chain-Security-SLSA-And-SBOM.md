# 04 — Software Supply Chain Security: SLSA, SBOM & Cosign Attestation

> "Your code is only 12% of your production container. The other 88% is transitive NuGet packages, base OS layers, and CI build scripts. If you don't cryptographically verify provenance, you are running untrusted code."

---

## 1. STRIDE & Supply Chain Threat Model (SLSA Levels 1–4)

The **SLSA (Supply-chain Levels for Software Artifacts)** framework defends against dependency confusion, compromised build runners, and registry tampering:

```text
[Developer Commit (Signed GPG/SSH)]
       │
       ▼  (Threat 1: Compromised Dependency / Typosquatting -> Mitigate: NuGet Lockfile + Source Mapping)
[Ephemeral GitHub Runner (OIDC)]
       │
       ▼  (Threat 2: Tampered Build Output -> Mitigate: SLSA Level 3 Provenance + CycloneDX SBOM)
[Container Registry (ACR/ECR)]
       │
       ▼  (Threat 3: Mutable Tag Hijack ':latest' -> Mitigate: Cosign Keyless Signature + Kyverno Gate)
[Kubernetes Production Admission Controller]
```

| SLSA Level | Core Guarantee | Implementation Mechanism | Validation & Rollback |
|---|---|---|---|
| **SLSA 1** | Build process is fully scripted and generates provenance metadata. | GitHub Actions / Azure Pipelines YAML with build manifest output. | Verify provenance JSON exists in artifact bundle. |
| **SLSA 2** | Hosted version control + authenticated provenance generated by CI service. | Signed attestation generated via `actions/attest-build-provenance`. | `gh attestation verify oci://<image>@sha256:...` |
| **SLSA 3** | Hardened, isolated, ephemeral build environments; non-falsifiable provenance. | Ephemeral runners + keyless **Sigstore Cosign** OIDC signing + Rekor transparency log. | Kyverno / Ratify admission controller blocks unsigned pods. |

## 2. Enforcing Deterministic NuGet Restore & Source Mapping

Prevent **Dependency Confusion Attacks** (where an attacker publishes a higher version of `Company.Internal.Auth` to public `nuget.org`) using `nuget.config` Package Source Mapping and lockfiles:

```xml
<!-- nuget.config -->
<?xml version="1.0" encoding="utf-8"?>
<configuration>
  <packageSources>
    <clear />
    <add key="nuget.org" value="https://api.nuget.org/v3/index.json" protocolVersion="3" />
    <add key="internal-feed" value="https://pkgs.dev.azure.com/principal-org/_packaging/core/nuget/v3/index.json" protocolVersion="3" />
  </packageSources>

  <!-- CRITICAL: Pin namespace prefixes to exact feeds to make Dependency Confusion impossible -->
  <packageSourceMapping>
    <packageSource key="internal-feed">
      <package pattern="PrincipalJourney.*" />
      <package pattern="Company.Internal.*" />
    </packageSource>
    <packageSource key="nuget.org">
      <package pattern="*" />
    </packageSource>
  </packageSourceMapping>
</configuration>
```

## 3. Generating CycloneDX SBOM & Keyless Cosign Signing in CI

```yaml
# .github/workflows/supply-chain-sign.yml
permissions:
  contents: read
  packages: write
  id-token: write      # Required for Sigstore Fulcio keyless OIDC signing
  attestations: write

steps:
  - name: Restore with Locked Dependencies
    run: dotnet restore --locked-mode

  - name: Generate CycloneDX SBOM
    run: |
      dotnet tool install --global CycloneDX
      dotnet CycloneDX ./src/Api/Api.csproj -o ./artifacts -j -fn sbom.cdx.json

  - name: Sign Container Digest & Attach SBOM Attestation (Keyless Cosign)
    env:
      COSIGN_EXPERIMENTAL: "1"
    run: |
      # ALWAYS sign the immutable @sha256 digest, NEVER a mutable tag!
      IMAGE_DIGEST="ghcr.io/principal/order-api@${{ steps.build.outputs.digest }}"
      cosign sign --yes "$IMAGE_DIGEST"
      cosign attest --yes --predicate ./artifacts/sbom.cdx.json --type cyclonedx "$IMAGE_DIGEST"
```

## 4. Kubernetes Admission Enforcement (Kyverno Policy)

```yaml
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-cosign-signed-images-and-sbom
spec:
  validationFailureAction: Enforce
  background: false
  rules:
    - name: verify-cosign-signature
      match:
        any:
          - resources:
              kinds: ["Pod"]
              namespaces: ["prod-*"]
      verifyImages:
        - imageReferences: ["ghcr.io/principal/*"]
          mutateDigest: true
          required: true
          attestors:
            - entries:
                - keyless:
                    issuer: "https://token.actions.githubusercontent.com"
                    subject: "https://github.com/principal-org/*"
                    rekor:
                      url: https://rekor.sigstore.dev
```
